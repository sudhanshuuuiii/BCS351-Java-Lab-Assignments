# Assignment 10 – Switch and ArrayList

## 1. Experiment Title
Switch and ArrayList

## 2. Aim
To choose a branch using a switch statement and store and modify a list of numbers using an ArrayList.

## 3. Software / Tools Required
- Java Development Kit (JDK 27)
- Visual Studio Code
- Windows Operating System

## 4. Theory
A switch statement is used to execute a particular block of code based on the value of a variable. ArrayList is a resizable collection in Java that allows us to add, access, update and remove elements easily.

## 5. Algorithm / Procedure

### Question 1: Switch on Day Number
1. Initialize day with value 3.
2. Use a switch statement to check the day number.
3. Display the matching weekday.
4. Use the default case to display Invalid day.

### Question 2: Create and Inspect an ArrayList
1. Create an ArrayList of Integer.
2. Add four values: 10, 20, 30 and 40.
3. Print the list and its size.
4. Display the element at index 2.

### Question 3: Update and Remove ArrayList Items
1. Create an ArrayList and add four values.
2. Replace the element at index 1 with 25.
3. Remove the element at index 3.
4. Print the updated list and its size.

## 6. Input

### Question 1
day = 3

### Question 2
Values added: 10, 20, 30, 40.

### Question 3
Initial list: 10, 20, 30, 40.
Set index 1 to 25.
Remove index 3.

## 7. Output

### Question 1
Wednesday

### Question 2
List: [10, 20, 30, 40]
Size: 4
Element at index 2: 30

### Question 3
Updated list: [10, 25, 30]
Size: 3

## 8. Result
All three Java programs were successfully executed. The switch statement selected the correct weekday, and ArrayList operations were performed successfully.
