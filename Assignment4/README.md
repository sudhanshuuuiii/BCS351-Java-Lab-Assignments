Assignment 4: Writing Functions

Aim

Write functions with parameters and return values, and call them from the main method.

Software / Tools Required

- Programming Language: Java
- JDK: JDK 27
- IDE / Text Editor: Visual Studio Code
- Operating System: Windows

Theory

A function (method) is a block of code that performs a specific task. In Java, methods can accept parameters and return values. They help divide a program into smaller, reusable parts.

In this assignment, factorial, combination, permutation and maximum-value calculations are performed using user-defined methods.

Algorithm / Procedure

Question 1: Combination with Functions

1. Define "fact(int n)" to calculate the factorial using a loop.
2. Define "nCr(int n, int r)" using the factorial method.
3. Call "nCr(5, 2)" from the main method.
4. Print the result.

Question 2: Permutation with Functions

1. Define "fact(int n)" to calculate the factorial using a loop.
2. Define "nPr(int n, int r)" using the factorial method.
3. Call "nPr(5, 2)" from the main method.
4. Print the result.

Question 3: Find the Larger Number

1. Define "maxOf(int a, int b)" to accept two integer values.
2. Compare both values using an if-else statement.
3. Return the larger value.
4. Call "maxOf(14, 9)" from the main method and print the result.

Input

- Question 1: n = 5, r = 2.
- Question 2: n = 5, r = 2.
- Question 3: a = 14, b = 9.

Output

Question 1

5C2 = 10

Question 2

5P2 = 20

Question 3

Larger: 14

Result

All three Java programs were successfully executed. The programs demonstrate the use of methods with parameters and return values.
