# Assignment 9 – Matrices: Rows and Columns

## 1. Experiment Title
Matrices: Rows and Columns

## 2. Aim
To visit the rows and columns of a matrix using nested loops to print, add, and count its values.

## 3. Software / Tools Required
- Java Development Kit (JDK 27)
- Visual Studio Code
- Windows Operating System

## 4. Theory
A matrix is a two-dimensional array that stores elements in rows and columns. Nested loops are used to access and process its elements. We can use loops to print specific rows, calculate column sums, and count values that satisfy a given condition.

## 5. Algorithm / Procedure

### Question 1: Print First and Last Row
1. Create a 3×3 matrix.
2. Print the first row using a loop.
3. Print the last row using a loop.
4. Display both rows.

### Question 2: Sum of Each Column
1. Create a 3×3 matrix.
2. Initialize a sum variable for each column.
3. Add all elements of the current column.
4. Display the sum of each column.

### Question 3: Count Values Greater Than 5
1. Create a 3×3 matrix.
2. Initialize a counter to zero.
3. Traverse all elements using nested loops.
4. If an element is greater than 5, increase the counter.
5. Display the final count.

## 6. Input

### Question 1
Matrix:

1 2 3

4 5 6

7 8 9

### Question 2
Matrix:

1 2 3

4 5 6

7 8 9

### Question 3
Matrix:

1 2 3

4 5 6

7 8 9

## 7. Output

### Question 1
First row: 1 2 3

Last row: 7 8 9

### Question 2
Column 1 sum: 12

Column 2 sum: 15

Column 3 sum: 18

### Question 3
Values greater than 5: 4

## 8. Result
All three programs were successfully executed. The first and last rows were printed, column sums were calculated, and values greater than 5 were counted successfully.
