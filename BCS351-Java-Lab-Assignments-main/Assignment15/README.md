Assignment 15 – StringBuilder Methods

1. Experiment Title

StringBuilder Methods

2. Aim

Build and change text with StringBuilder, using append, insert and deleteCharAt.

3. Software / Tools Required

- Java JDK 27
- Visual Studio Code
- Windows Operating System

4. Theory

StringBuilder is a Java class used to create and modify mutable sequences of characters. The "append()" method adds text at the end, "insert()" adds text at a specified position, and "deleteCharAt()" removes a character at a given index. The "length()" method returns the number of characters.

5. Algorithm / Procedure

Question 1: Append and Length

1. Create a StringBuilder containing ""Hello"".
2. Append "" World"" to it.
3. Print the updated text.
4. Print its length.

Question 2: Remove Last Comma

1. Create an empty StringBuilder.
2. Append numbers from 1 to 5, each followed by a comma.
3. Remove the last comma using "deleteCharAt()".
4. Print the result.

Question 3: Insert Text

1. Create a StringBuilder containing ""Java"".
2. Insert ""Hello "" at index 0.
3. Print the updated text.

6. Input

- Question 1: "Hello"
- Question 2: Numbers from 1 to 5
- Question 3: "Java"

7. Output

Question 1

Hello World

Length: 11

Question 2

1,2,3,4,5

Question 3

Hello Java

8. Result

All three Java programs were executed successfully. The programs demonstrated the use of StringBuilder methods append(), insert(), deleteCharAt(), and length().
