# Assignment 5: Arrays – Traversal and Counting

## 1. Experiment Title
Arrays: Traversal and Counting

## 2. Aim
To create an array, visit every element using a loop, and add up or count the values.

## 3. Software / Tools Required
- Java Development Kit (JDK 27)
- Visual Studio Code
- Windows Operating System

## 4. Theory
An array in Java is a collection of elements of the same data type stored under a single variable name. Each element is accessed using its index, starting from 0.

Loops are used to traverse arrays and perform operations such as calculating the sum, finding the largest element, and counting values that satisfy a condition. The `length` property gives the total number of elements in an array.

## 5. Algorithm / Procedure

### Question 1: Print Array Elements with Index
1. Create an integer array containing 3, 4, and 5.
2. Use a for loop to traverse the array.
3. Print each element along with its index.

### Question 2: Find Sum and Largest Element
1. Create an integer array containing 12, 45, 7, 33, and 21.
2. Initialize sum to 0 and largest with the first array element.
3. Traverse the array using a for loop.
4. Add each element to sum.
5. Compare each element with largest and update it if necessary.
6. Print the sum and largest value.

### Question 3: Count Values Greater Than 10
1. Create an integer array containing 5, 12, 2, 14, and 7.
2. Initialize a counter to 0.
3. Traverse the array using a for loop.
4. If an element is greater than 10, increase the counter.
5. Print the final count.

## 6. Input

- Question 1: Array values are 3, 4, 5.
- Question 2: Array values are 12, 45, 7, 33, 21.
- Question 3: Array values are 5, 12, 2, 14, 7.

## 7. Output

### Question 1
```text
Index 0: 3
Index 1: 4
Index 2: 5
```

### Question 2
```text
Sum: 118
Largest: 45
```

### Question 3
```text
Count greater than 10: 2
```

## 8. Result
Successfully created and traversed arrays using loops. Calculated the sum, found the largest element, and counted elements greater than 10.
