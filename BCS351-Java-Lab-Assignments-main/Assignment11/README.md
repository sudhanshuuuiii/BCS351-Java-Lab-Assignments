Assignment 11: Bubble Sort and Selection Sort

1. Experiment Title

Bubble Sort and Selection Sort

2. Aim

To sort small arrays using bubble sort and selection sort, and count the swaps performed during bubble sort.

3. Software / Tools Required

- Java Development Kit (JDK 27)
- Visual Studio Code
- Windows Operating System

4. Theory

Bubble Sort: Bubble sort compares adjacent elements and swaps them if they are in the wrong order. This process repeats until the array is sorted.

Selection Sort: Selection sort finds the smallest element in the unsorted part of the array and places it at the correct position.

Swap Counting: A swap occurs whenever two elements exchange their positions during sorting.

5. Algorithm / Procedure

Question 1: Bubble Sort

1. Initialize the array with values 5, 1, 4, 2, 8.
2. Compare adjacent elements.
3. Swap elements if they are in the wrong order.
4. Repeat the passes until the array is sorted.
5. Print the sorted array.

Question 2: Selection Sort

1. Initialize the array with values 64, 25, 12, 22, 11.
2. Find the smallest element in the unsorted part.
3. Swap it with the first element of the unsorted part.
4. Repeat until the array is sorted.
5. Print the sorted array.

Question 3: Count Bubble Sort Swaps

1. Initialize the array with values 5, 1, 4, 2, 8.
2. Set the swap counter to zero.
3. Perform bubble sort.
4. Increase the counter whenever two elements are swapped.
5. Print the total number of swaps.

6. Input

- Question 1: 5, 1, 4, 2, 8
- Question 2: 64, 25, 12, 22, 11
- Question 3: 5, 1, 4, 2, 8

7. Output

Question 1

Sorted: [1, 2, 4, 5, 8]

Question 2

Sorted: [11, 12, 22, 25, 64]

Question 3

Swaps: 4

8. Result

Successfully implemented bubble sort and selection sort in Java and counted the swaps performed during bubble sort.
