Assignment 14 – Characters: Counting and Positions

1. Experiment Title

Characters: Counting and Positions

2. Aim

Use "charAt()" to count vowels and a letter, and print each letter with its position.

3. Software / Tools Required

- Java JDK 27
- Visual Studio Code
- Windows Operating System

4. Theory

In Java, the "charAt()" method is used to access a character at a specific index in a string. String indexing starts from 0. It can be used to count vowels, find occurrences of a character, and display characters with their positions.

5. Algorithm / Procedure

Question 1: Count Vowels

1. Store ""programming"" in a String variable.
2. Initialize a counter to 0.
3. Check each character for vowels (a, e, i, o, u).
4. Increase the counter when a vowel is found.
5. Print the total count.

Question 2: Count Letter g

1. Store ""programming"" in a String variable.
2. Initialize a counter to 0.
3. Check each character for the letter "g".
4. Increase the counter whenever "g" is found.
5. Print the count.

Question 3: Character Positions

1. Store ""hello"" in a String variable.
2. Use a loop to visit each character.
3. Print its index followed by the character.

6. Input

- Question 1: "programming"
- Question 2: "programming"
- Question 3: "hello"

7. Output

Question 1

Vowels: 3

Question 2

Count of g: 2

Question 3

0: h

1: e

2: l

3: l

4: o

8. Result

All three Java programs were executed successfully. The programs counted vowels, counted occurrences of a character, and displayed each character with its position.
