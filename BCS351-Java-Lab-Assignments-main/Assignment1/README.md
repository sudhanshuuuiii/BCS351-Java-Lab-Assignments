Hello World, Variables and Arithmetic

To print text, store values in variables and perform calculations using arithmetic operators in Java.

1. Programming Language: Java

4. Theory

1. Output Statements:

Java provides the "System.out.println()" statement to display text and values on the console. It prints the output and moves the cursor to the next line.

2. Variables:

Variables are named memory locations used to store data.

Java data types used in this experiment:

- "int": Stores integer values.
- "double": Stores decimal values.
- "char": Stores a single character.
- "String": Stores a sequence of characters.

3. Arithmetic Operators:

Java provides arithmetic operators to perform mathematical calculations.

- "+": Addition
- "-": Subtraction
- "*": Multiplication
- "/": Division
- "%": Modulus (Remainder)

4. Constant:

The "final" keyword is used to declare a constant whose value cannot be changed after initialization.

5. Circle Formulas:

Area = PI × radius × radius

Perimeter = 2 × PI × radius
