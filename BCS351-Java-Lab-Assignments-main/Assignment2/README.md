Assignment 2: Decisions and Loops with Numbers

1. Experiment Title

Decisions and Loops with Numbers

2. Aim

To use if, else-if and loops to make decisions and repeat steps with whole numbers.

3. Software / Tools Required

- Programming Language: Java
- JDK: JDK 27
- IDE / Text Editor: Visual Studio Code
- Operating System: Windows

4. Theory

Decision-making statements in Java are used to execute different blocks of code based on conditions. The "if", "else-if" and "else" statements help a program make decisions.

The modulus operator ("%") gives the remainder after division and can be used to check whether a number is even or odd. Loops are used to repeat a block of code. A "for" loop is useful when the number of repetitions is known.

5. Algorithm / Procedure

Question 1: Even or Odd

1. Start the program.
2. Store 27 in an integer variable "n".
3. Check whether "n % 2 == 0".
4. If true, print that the number is even; otherwise, print that it is odd.
5. Stop the program.

Question 2: Grade Calculation

1. Start the program.
2. Store 83 in an integer variable "marks".
3. Check whether marks are 90 or more.
4. If not, check whether marks are 75 or more.
5. Print Grade A, B or C according to the conditions.
6. Stop the program.

Question 3: Leap Year

1. Start the program.
2. Store 2024 in an integer variable "year".
3. Check whether the year is divisible by 4 but not by 100, or divisible by 400.
4. If the condition is true, print Leap year.
5. Otherwise, print Not a leap year.
6. Stop the program.

Question 4: Factorial Using a For Loop

1. Start the program.
2. Initialize "factorial" to 1.
3. Use a for loop from 1 to 5.
4. Multiply "factorial" by each loop value.
5. Print the factorial of 5.
6. Stop the program.

6. Input

Question 1

"n = 27"

Question 2

"marks = 83"

Question 3

"year = 2024"

Question 4

Number = 5

7. Output

Question 1

27 is odd

Question 2

Grade: B

Question 3

Leap year

Question 4

Factorial of 5 is 120

8. Result

All four Java programs were successfully executed. The use of if, else-if, modulus operator and for loop was practised and understood.
