Assignment 12: Insertion Sort

1. Experiment Title

Insertion Sort

2. Aim

To sort small arrays using insertion sort and count how many values are shifted.

3. Software / Tools Required

- Java Development Kit (JDK 27)
- Visual Studio Code
- Windows Operating System

4. Theory

Insertion sort is a sorting technique that builds a sorted array one element at a time. It takes each element and inserts it into its correct position by shifting larger elements to the right.

A shift occurs whenever an element moves one position to the right to make space for the selected element.

5. Algorithm / Procedure

Question 1

1. Initialize the array with values 7, 3, 5, 1.
2. Select an element as the key.
3. Compare the key with previous elements.
4. Shift larger elements one position to the right.
5. Insert the key at its correct position.
6. Print the sorted array.

Question 2

1. Initialize the array with values 14, 3, 9, 21, 6.
2. Select each element as the key.
3. Compare it with previous elements.
4. Shift larger elements to the right.
5. Insert the key at its correct position.
6. Print the sorted array.

Question 3

1. Initialize the array with values 6, 5, 4, 3, 2, 1.
2. Initialize the shift counter to zero.
3. Perform insertion sort.
4. Increase the counter whenever an element shifts one position to the right.
5. Print the total number of shifts.

6. Input

- Question 1: 7, 3, 5, 1
- Question 2: 14, 3, 9, 21, 6
- Question 3: 6, 5, 4, 3, 2, 1

7. Output

Question 1

Sorted: [1, 3, 5, 7]

Question 2

Sorted: [3, 6, 9, 14, 21]

Question 3

Shifts: 15

8. Result

Successfully implemented insertion sort in Java and counted the number of shifts performed during sorting.
